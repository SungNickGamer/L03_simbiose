# Modelo de Casos de Uso

## 1. Introducción
Este documento presenta el Modelo de Casos de Uso para el proyecto Simbiosis, correspondiente al alcance definido en el apartado 4 del Plan de Iteración. Describe las interacciones principales entre los actores y el sistema para facilitar la economía circular e intercambio de subproductos industriales.

## 2. Actores
* **Usuario Registrado:** Usuario autenticado en la plataforma que puede realizar búsquedas, solicitar intercambios y valorar transacciones finalizadas.
* **Empresa Oferente:** Entidad registrada con permisos para publicar, modificar y gestionar sus subproductos e insumos ofertados.
* **Administrador:** Encargado de la supervisión general del sistema, validación de cuentas y moderación de contenidos.

## 3. Casos de Uso
* **CU-01: Publicar Subproducto:** Permite a una Empresa Oferente dar de alta un nuevo subproducto especificando categoría, cantidad y ubicación.
* **CU-02: Buscar/Filtrar Subproductos:** Permite a los usuarios buscar subproductos aplicando filtros geográficos y por tipo de material.
* **CU-03: Gestionar Solicitudes de Intercambio:** Permite tramitar, aceptar o rechazar solicitudes de intercambio entre partes interesados.
* **CU-04: Valorar Transacción:** Permite a las partes calificar y emitir comentarios sobre el intercambio realizado.
